# Frontend Route Authority Matrix

This matrix is the human-readable projection of the typed frontend route
manifest. The manifest remains the executable authority for classification,
normal navigation, canonical ownership, capability metadata, permission
metadata, and direct-access behavior.

Route permission metadata is descriptive. It never replaces tenant-scoped API
authorization or server-side permission checks.

- Core: 57
- Extension: 72
- Internal: 18
- Frozen: 7
- Legacy: 5
- Total: 159

## Default SME navigation

Receiving, Inventory, Suppliers, and Items. Universal Intake and Review Queue
are added in deterministic positions only when their explicit preview
capabilities are enabled. The existing global AI Assistant action is an
application action, not a standalone route.
